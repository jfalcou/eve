Return value

  1. Returns the elementwise hyperbolic cosine of the input. In particular:
    • If the element is \(\pm0\), \(1\) is returned.
    • If the element is \(\pm\infty\), \(+\infty\) is returned.

  2. The operation is performed conditionally.
