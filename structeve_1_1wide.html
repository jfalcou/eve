Detailed Description

template<arithmetic_scalar_value Type, width_type Width>
requires (is_valid_width<Width>)
struct eve::wide< Type, Width >

Wrapper for SIMD registers.

Required header: #include <eve/wide.hpp>

eve::wide is an architecture-agnostic representation of a SIMD register and provides standardized API to access information, compute values and manipulate such register.

Template Parameters
TypeType of value to store in the register
SizeLane count of the register. By default, the best size for the current architecture is selected.
